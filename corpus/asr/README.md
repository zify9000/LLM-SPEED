# corpus/asr/ — 语音转写测速语料（可选）

把用于测速的音频文件（**wav 格式**）放在本目录，测速时优先使用这里的语料：

- 只取排序后的第一个文件，按目标时长**首尾循环拼接**（帧级精确截取），默认时长阶梯 5s~1800s 都由它生成
- 推荐：真人语音、≥60 秒、16kHz+ 单声道/双声道均可；如服务端带 VAD，请确保不是静音/纯噪音（合成兜底音不会被 VAD 短路，但真人语音永远优先）
- 非 wav 格式请先转码（如 `ffmpeg -i a.mp3 -ac 1 -ar 16000 a.wav`）

目录为空（或不存在）时自动回退**内置合成语料**：speech-like 音频（基音谐波 + 音节率包络），
确定性生成、零依赖——ASR 编码器负载只取决于时长×采样率，合成音是等价的测速负载。

> 本目录是**用户自备通道**，仓内不 vendored 任何音频（当前目录只有本 README），
> 因此不需要 `PROVENANCE.md`。注意：一旦放入音频，**该音频就成为你这台机器上
> 的测量刻度**——换音频会让前后两次 ASR 读数不可比（负载按时长归一，但内容会
> 影响 VAD/分块行为）。若要长期使用，建议把文件与来源记在本地。

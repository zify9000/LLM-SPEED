# corpus/ocr/ — 图像识别测速语料（可选）

把用于测速的图片（**png / jpg / jpeg**）放在本目录，测速时优先使用这里的语料：

- 全部文件进入图池，按请求在池内轮转取图（张数阶梯 1~16 张/请求），分辨率/版面越多样越好
- 推荐：真实扫描页/拍照文档（含文字），如 1240×1754（A4@150dpi）~ 2480×3508（A4@300dpi）
- 图片经 base64 内联进请求体，单张建议 ≤2MB

目录为空（或不存在）时自动回退**内置合成语料**：3 种分辨率的伪文本文档页，
确定性生成、零依赖——VLM 视觉编码负载取决于分辨率与图文密度，合成页是等价的测速负载。
